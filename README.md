# מנטור מעבדה לפיזיקה

מערכת הדרכה למעבדת פיזיקה: מנטור AI שמלווה תלמידים בעמדת ניסוי (עמדה 1: מנוע תלת־פאזי עם וסת תדר), ומסך מורה לשיעור חי.
המאגר מרכז את מסמכי האפיון והעיצוב שהופקו לפרויקט. עדיין אין בו קוד.

## מצב הפיתוח

- **שלב 1 · מסך תלמיד:** תרגיל EX-01 מקצה לקצה על ההקלטות הסינתטיות: רקע ושאלת הבנה, תחזית, צפייה עד נקודת העצירה, השערה, איסוף ראיות מהגרף, נימוק עם אבחון, בדיקה חוזרת ושאלת יציאה. EX-02 עד EX-04 נטענים, והתוכן שלהם עדיין טיוטה.
- **שלב 2 · מסך מורה:** שיעור עם קוד הצטרפות, כרטיסי עמדות לפי דחיפות, התראות עם הצעת התערבות, השהיה, רמז והודעה לעמדה, יומן עמדה ומחוון מוצע.
- **שלב 3 · Claude כמנטור:** Claude מנסח רמזים ומשוב, ועונה על שאלה חופשית של התלמיד. מודל מהיר מסווג טקסט חופשי בשביל המורה. כל ניסוח עובר מאמת: עד שני משפטים, מסתיים בשאלה, בלי מונחים שחושפים את התשובה, רק מספרים שהתלמיד ראה, בלי הוראה פיזית. אם הניסוח נכשל במאמת, יש ניסיון חוזר אחד ואחריו המערכת חוזרת לטקסט המאושר. Claude לא מחליט אם התלמיד צודק. **בלי מפתח API המערכת עובדת עם הטקסטים המאושרים בלבד.**

**הפעלת Claude:** מגדירים משתנה סביבה `ANTHROPIC_API_KEY` לפני הפעלת השרת. המודלים: `claude-opus-5-5` לניסוח ו־`claude-haiku-5-5` לסיווג. אפשר להחליף אותם ב־`LLM_MODEL_PHRASE` וב־`LLM_MODEL_CLASSIFY`. בדיקת עמידות מול ״תלמידים מדומים״ שמנסים לחלץ תשובה: `python3 tools/eval/adversarial.py`.

| תיקייה | תוכן |
|---|---|
| `apps/api/` | שרת Python (FastAPI): ייבוא נתונים, מכונת המצבים, שער הזמן, מנוע האבחון, API |
| `apps/web/` | מסך העמדה (React) |
| `content/` | תוכן התרגילים, קטלוג הערוצים, ומפתח התשובות (`answer_key.yaml`, לשרת בלבד) |

- **שלב 4 · השלמות להדגמה:** תרגיל EX-05 (שתי ההרצות התקינות ברצף), שמירת סשנים ושיעורים לדיסק כך שאתחול השרת לא מוחק שיעור פעיל, סקריפט הפעלה וקובץ Docker.

- **שלב 5 · הכנה לעמדה חיה ולפיילוט:** מעטפת בטיחות לפי מוח 1 (`content/envelope.yaml`, כל הערכים ״מוצע״ עד אישור תלם) עם התראת בטיחות למורה בראש המסך. קליטת נתונים מבקר העמדה בפרוטוקול `obs.v1`: קוד מכשיר, מסגרות שנשלחות שוב לא נקלטות פעמיים, ספירת פערים. סימולטור של בקר העמדה, מסך ניטור ערוצים חי, אישור ציון בידי המורה, וייצוא ציונים ל־CSV.

- **שלב 6 · כניסת מורים:** חשבון לכל מורה, סיסמה שנשמרת רק כגיבוב (PBKDF2 עם מלח), עוגיית כניסה חתומה לתוקף 12 שעות, נעילה ל־5 דקות אחרי 5 ניסיונות שגויים. כל מורה רואה רק את השיעורים שלו. תלמידים לא צריכים כניסה: הם מצטרפים עם קוד השיעור. התלמיד רואה רק את מספר התרגיל, והמורה רואה גם את שמו.

**הוספת מורה:**

```bash
python3 tools/add_teacher.py rita "ריטה"
```

הסיסמה נשאלת פעמיים ולא מוצגת. אותה פקודה מאפסת סיסמה למשתמש קיים. כל עוד לא הוגדר אף מורה, המערכת ב**מצב הדגמה**: מסכי המורה פתוחים לכל מי שמגיע, ופס צהוב אומר זאת. בשרת אמיתי מגדירים `SECRET_KEY` (מחרוזת אקראית ארוכה) ו־`COOKIE_SECURE=1` מאחורי HTTPS.

### הרצה מקומית

נדרשים Python 3.11 ומעלה ו־Node.js 20 ומעלה. פקודה אחת מתקינה, בונה ומפעילה:

```bash
./run.sh
```

אחר כך פותחים את http://localhost:8000. בדיקות: `cd apps/api && python3 -m pytest`.

| כתובת | מסך |
|---|---|
| `/teacher` | מסך מורה: פתיחת שיעור, כרטיסי עמדות, התראות, מחוון, יומן עמדה |
| `/teacher/login` | כניסת מורים |
| `/join` | הצטרפות עמדה לשיעור עם קוד בן 6 ספרות |
| `/demo` | תרגול בלי שיעור |

הגדרות שרת להדגמה: `REPLAY_SPEED=4` מנגן את ההקלטה מהר יותר. `STUCK_SECONDS=60` מקצר את הזמן עד התראת ״תקוע״ (ברירת מחדל 300). `TEACHER_TOKEN=...` מאפשר לסקריפטים לגשת ל־API של המורה עם הכותרת `X-Teacher-Token`.

### Docker

```bash
docker build -t lab-mentor .
docker run -p 8000:8000 -v lab-state:/app/var -e ANTHROPIC_API_KEY=... lab-mentor
```

הסשנים, השיעורים ויומן הלמידה נשמרים בתיקייה `var/`, ובקונטיינר זה ה־volume שנקרא `lab-state`. קובץ ה־Docker עוד לא נבדק עד הסוף: בסביבת הפיתוח החסימות ברשת לא אפשרו להשלים את הבנייה.

### עמדה חיה (הדגמה עם סימולטור)

בקר העמדה שולח מסגרת `obs.v1` בכל שנייה אל `POST /api/edge/stations/<station>/obs`, עם הכותרת `X-Device-Token`. קוד המכשיר נקבע ב־`EDGE_TOKEN`. ברירת המחדל `dev-edge-token` מיועדת להדגמה בלבד. כדי לראות זאת בלי עמדה אמיתית מפעילים את השרת, ואז:

```bash
python3 tools/simulator/station_agent.py --run E04 --speed 2
```

אחר כך פותחים את http://localhost:8000/monitor. הסימולטור מנגן הקלטה כאילו היא מגיעה מהעמדה, ואם השרת לא זמין הוא שומר את המסגרות בתור ושולח אותן כשהשרת חוזר. היסטוריית הנתונים החיים נשמרת בזיכרון (10 דקות) ולא בדיסק.

### כלים

- `python3 tools/simulator/make_healthy.py` יוצר את ההרצות התקינות N01–N03 (`data/TLM_Rita_Normal_SIMULATED.csv`) לפי מפרט `TLM_Rita_02_Healthy.docx`, ובודק את כל ערכי הייחוס שבמפרט.
- `python3 tools/content_review.py` מעדכן את [docs/05-content-review.md](docs/05-content-review.md), דף קריא של תוכן התרגילים לבדיקת המורה.
